#  Project Name :
   BazarDor (বাজার দর)

## About the Project : 
BazarDor is a simple web application that helps people check the prices of everyday essentials in Bangladesh. Users can explore different product categories, compare prices, and view product details in one place. The goal is to make daily market price information easier to access.

## Technologies Used  :
- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI
- Better Auth
- REST API

## Key Features

- **Live Product Data:** Fetches product and category information from an API.
- **Product Categories:** Browse everyday essentials by category.
- **Price Sorting:** Sort products from lowest to highest price or vice versa.
- **Product Details:** View detailed information about individual products.
- **User Authentication:** Sign up and sign in using Better Auth.
- **Responsive Design:** Works on mobile, tablet, and desktop devices.
- **Price Ticker:** View product prices and price changes in a scrolling ticker.
